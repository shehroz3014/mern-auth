# MERN Auth

A full-stack authentication application built with MongoDB, Express.js, React, and Node.js.

## Features
- User Signup
- User Login
- Authentication API
- React Frontend
- Express.js Backend
- MongoDB Integration

## Project Structure
- `backend/` - Express.js API
- `frontend/` - React application

## Installation

Install backend dependencies:
cd backend
npm install

Install frontend dependencies:
cd frontend
npm install
